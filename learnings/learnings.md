| 2026-10-02 | Root-relative URLs (`/image.jpg`) break on GitHub Pages | GitHub Pages hosts under a repository subpath (`/<repo>/`) where `/` points to `<username>.github.io` | Always use relative paths (`./`) or ES module imports (`import img from '../assets/...'`) |
| 2026-10-02 | Windows user PATH changes are not auto-inherited by active child shells | Registry updates to User PATH require terminal restart or explicit session prefixing | Explicitly verify and load `$env:LOCALAPPDATA\Programs\Git\cmd` in script runners |
| 2026-10-02 | Vite deduplicates identical binary assets | Identical files with same SHA256 hashes produce a single hashed asset chunk | Check file hash equality when diagnosing unexpected asset count in `dist/` |
| 2026-10-02 | Token minimization requires progressive context loading | Dumping full files into context wastes tokens and slows iteration | View targeted slices and maintain structured specs in `superpowers/specs/` |
| 2026-10-02 | Cognitive load reduction drives recruiter conversion | 10-tab sprawling portfolios trigger reader fatigue within 8 seconds | Spotlight Top 3 flagship systems, gate deep specs behind progressive disclosure modals |
| 2026-10-02 | Truthful attribution outconverts fabricated metrics in technical hiring | Technical managers immediately probe suspicious numbers ($120k savings, 98% reduction); nuanced contribution verbs (Contributed, Modeled, Collaborated) and clear project status badges (COMPLETED, IN PROGRESS, PLANNED) build authentic credibility | Label conceptual initiatives as 'Portfolio Case Studies' and strictly separate current AI development from planned roadmap items |
| 2026-10-02 | Async Browser APIs (`navigator.clipboard`, `window.scrollTo`) require defensive guards in SSR/test environments | In headless test runs or non-HTTPS domains, `navigator.clipboard` or `window.scrollTo` may be undefined or throw unhandled rejections | Guard with `if (navigator?.clipboard?.writeText)` and stub global browser methods in test setup files |
| 2026-10-03 | Mobile iOS Safari auto-zooms inputs under 16px font-size; complex pipelines require touch swipe-scroll | Form inputs with `font-size < 16px` trigger aggressive automatic viewport zooming on iOS Safari focus, breaking layout; 7-stage desktop grids squeeze into unreadable boxes on mobile | Enforce `font-size: 16px` on all mobile text inputs/textareas, use fluid `clamp()` on long headlines, and wrap multi-stage pipelines in `overflow-x: auto` with touch snap |
| 2026-10-03 | CSS 100vw vs 100% creates white strip / horizontal scrollbar on Windows | On Windows/browsers with classic scrollbars, 100vw includes the 17px vertical scrollbar width, causing the body to overflow the viewport horizontally and exposing background margin shifts | Never use width: 100vw on root document elements (#root, html, body, main wrapper); use width: 100% instead |
| 2026-10-03 | Flex children default to min-width: auto, ignoring parent width limits on long strings | Without min-width: 0, a flex child containing an unbroken string (e.g. email address or phone) pushes parent cards beyond the grid column width, clipping borders off-screen on laptop viewports (1024px-1180px) | Always declare min-width: 0, overflow-wrap: anywhere, and word-break: break-word on flex containers wrapping user strings |
| 2026-10-03 | FormSubmit.co provides zero-config, secretless email delivery for static sites | Static SPAs on GitHub Pages cannot run server-side SMTP mailers without exposing sensitive credentials or spinning up backend Lambdas | Post async JSON to https://formsubmit.co/ajax/<email> with _replyto and _captcha headers, while providing an offline mailto fallback for total delivery reliability |
| 2026-10-03 | Recruiter Self-Directed Q&A Consoles (`// ask_...exe`) Deliver Higher Conversion Than Sprawling Biographies | Recruiters spend <30 seconds on initial portfolio scans. Long multi-section resumes create decision paralysis and drop-off. By pairing an interactive Q&A console (short, punchy answers with direct jump links) with segmented multi-view tab containers, recruiters immediately find answers to their specific qualification questions without endless scrolling. | Implement conversational quick-answer consoles above the fold, and consolidate related deep artifacts into tabbed/segmented containers rather than stacking them into 10+ vertical sections. |
| 2026-10-03 | Element scrollTo requires scrollTop fallback in jsdom/SSR environments | In headless virtual DOM (jsdom), `Element.prototype.scrollTo` is not polyfilled and throws TypeError, while `scrollTop` assignment works universally | Always check `typeof el.scrollTo === 'function'` before invoking smooth scroll, with `el.scrollTop = el.scrollHeight` fallback |
| 2026-10-03 | Multi-Perspective Toggles Must Visually Transform Underlying Content | A UI toggle that only modifies helper text or button state without filtering or transforming the underlying content gives the user the impression that the feature is broken. | When building dual-audience toggles (e.g. Executive vs Technical), strictly gate and differentiate the components rendered in each view, providing reciprocal call-to-action prompts so users can switch seamlessly between views without confusion. |
| 2026-10-03 | Component Consolidation Requires Intentional Dead Code Auditing | When consolidating multi-section architectures into unified segmented tab containers, the original standalone components and their dedicated data files become orphaned if not actively removed. | Regularly run automated AST/regex dependency graph audits across the project to purge unreferenced JSX files, obsolete mock datasets, and unused static assets, keeping the repository lean, fast-building, and easily maintainable. |
