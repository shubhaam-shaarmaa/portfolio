# Superpowers Directory

This folder houses the tools, specifications, and skills that enable autonomous, token-efficient, and secure pair-programming in this project.

## Directory Structure
- **`specs/`**: Contains active and completed feature specifications created prior to implementation.
  - [`template_spec.md`](specs/template_spec.md): Standard template for new feature specs.
- **`skills/`**: Reusable skills, runbooks, and playbooks.
  - [`autonomous_development.md`](skills/autonomous_development.md): Playbook for high efficiency, token minimization, and security guardrails.
